# Sequential Downloader Benchmark

Простой консольный скрипт на Node.js, который делает 10 последовательных GET-запросов к указанному URL и дожидается полного ответа. Скрипт не сохраняет файл на диск, а пропускает его через потоки, чтобы корректно посчитать объём переданных данных без переполнения памяти.

## Требования
- Node.js (рекомендуется v14+)
- Отсутствие дополнительных NPM-зависимостей (используются только встроенные модули).

## Использование

Запустите скрипт через Node.js, передав целевой адрес в качестве аргумента.

```bash
node index.js [https://example.com/heavy-image.jpg](https://example.com/heavy-image.jpg)
